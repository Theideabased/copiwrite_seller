# WhatsApp Views-to-Sales video slides

The recording-ready 16:9 deck is available at:

`/sell-on-whatsapp/slides`

## Present the deck

- Run `npm run dev` and open `http://localhost:3000/sell-on-whatsapp/slides`.
- Use the left/right arrow keys, Page Up/Page Down, or Space to move through slides.
- Press `F` or use the fullscreen button before recording.
- Use Home or End to jump to the first or last slide.

## Save it as a PDF

1. Open the deck in Chrome or Edge.
2. Select the printer button below the deck, or use the browser's Print command.
3. Choose **Save as PDF**.
4. Choose **Landscape**, turn **Background graphics** on, set margins to **None**, and use 100% scale.

The print stylesheet exports every slide at a 16:9 page size. The on-screen navigation is excluded from the PDF.

The full voiceover remains in `sales_video_script.md`. The deck intentionally uses less text so viewers listen to the presenter rather than read the script from the screen.
